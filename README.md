# Key-Value Store in C

A simple key-value store implemented in C as part of my Low Level Academy learning journey.

## About

This project is focused on learning C by building a basic key-value store from scratch.

The store uses a simple:

`key -> value`

model for storing and retrieving data.

## Goals

* Learn C through a practical project
* Understand memory management
* Practice using structs and pointers
* Work with file I/O
* Understand basic data storage and retrieval
* Write clean and modular C code

## Build

```bash
make
```

## Run

```bash
./kvstore
```
